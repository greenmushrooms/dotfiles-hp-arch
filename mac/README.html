dotfiles_clean

A keyboard-driven macOS desktop, rebuilt in one command: AeroSpace tiling, SketchyBar, a focus border, Ghostty + Nushell + Starship, Neovim, and a vim-mode Firefox. This repo is only the portable, ease-of-use layer: no work config, credentials, or cloud wrappers.

Install (repeatable)

xcode-select --install          # once: git + /usr/bin/python3
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"   # once: Homebrew
git clone <this repo> ~/projects/dotfiles_clean
cd ~/projects/dotfiles_clean
./install.sh --dry-run          # see what it would change
./install.sh

You can run install.sh again at any time. Correct links and files report ok. Anything else in the way is moved to <name>.bak.<timestamp>, never deleted.

  1. brew bundle: installs anything in Brewfile that's missing.
  2. Symlinks every config into place, so edits in the repo are live.
  3. Services: starts or restarts SketchyBar and JankyBorders, and launches or reloads AeroSpace.
  4. Firefox: autoconfig into the app bundle; user.js and userChrome/userContent.css into the active profile; a LaunchAgent serving the start page on localhost:8347; Tridactyl's native messenger and extension.

Flags: --dry-run (change nothing), --no-brew (configs only).

Manual steps that macOS won't let a script do

  • System Settings → Privacy & Security → Accessibility → allow AeroSpace.
  • System Settings → Control Center → Automatically hide and show the menu bar → Always, so SketchyBar takes the strip.
  • Optional: ./macos/defaults.sh (Mission Control groups by app, one Space across displays, hidden menu bar). Log out afterwards.
  • First nvim launch clones the plugins. Then run :CopilotSignIn if you want Copilot.
  • After a Firefox update, re-run ./install.sh, because the update replaces the app bundle and the autoconfig with it.

Changing things

  • Add a package: add a line to Brewfile, then run ./install.sh.
  • Add an nvim plugin: add { src = "https://github.com/owner/repo" } to vim.pack.add in nvim/init.lua, create nvim/lua/plugins/<name>.lua, and require it from lua/plugins/init.lua. Update plugins with :lua vim.pack.update() and commit nvim-pack-lock.json.
  • Add a shortcut: edit the config, then update both README.md and this file.
  • Machine-specific extras (work wrappers, secrets-adjacent PATHs): put a *.nu file in ~/Library/Application Support/nushell/autoload/, never in this repo.
